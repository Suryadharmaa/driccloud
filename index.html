// BEFORE YOU SHIP

Pertanyaan yang
sering mampir.

Masih ada yang mengganjal? Buka bot dan pilih Hubungi Admin.

Bagaimana cara membeli RDP?

Pilih paket di halaman ini untuk membuka @DriccloudBot. Bot menampilkan detail paket dan invoice QRIS dengan nominal unik. Setelah admin memverifikasi dana masuk, engine menyiapkan instance dan mengirim notifikasi.

Bisa konek dari Windows dan Android?

Bisa. Windows: buka Remote Desktop Connection, lalu isi host:port dari panel Telegram. Android: gunakan Windows App/Remote Desktop dan tambahkan PC dengan alamat yang sama. Shortcut .rdp juga bisa diunduh dari bot.

Apakah Telegram harus terus terbuka?

Tidak. Telegram adalah tempat mengelola server. Bot dan aplikasi di dalam Windows tetap berjalan selama instance menyala dan masa layanan aktif. *Ketersediaan layanan mengikuti kondisi node dan pemeliharaan.

Apakah data hilang saat perpanjangan?

Perpanjangan pada instance yang sama menambah masa aktif tanpa menginstal ulang Windows. Reinstall adalah tindakan terpisah yang menghapus data dan membutuhkan dua langkah konfirmasi.

Bolehkah menjalankan bot dan AI agent?

Boleh selama sesuai kapasitas paket, izin penggunaan aplikasi/API, dan hukum yang berlaku. Mining, spam, phishing, malware, dan serangan jaringan dilarang. API key, lisensi, serta akun layanan pihak ketiga disediakan sendiri.
